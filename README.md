# باشگاه تجربه الفبا — Android Studio

نسخه MVP یک اپلیکیشن باشگاه آموزشی/تجربه‌محور.

## امکانات فعلی
- خانه و اطلاعیه‌ها
- برنامه‌ها و رویدادها
- پروفایل عضو
- ستاره و سطح
- تعداد جلسات
- امور مالی و سوابق پرداخت
- رابط فارسی و RTL

## اجرای پروژه
1. Android Studio را نصب کنید.
2. این پوشه را با `Open` باز کنید.
3. صبر کنید Gradle Sync کامل شود.
4. از منوی Build گزینه `Build APK(s)` را انتخاب کنید.

این نسخه برای اتصال به Backend/Firebase در مرحله بعد آماده شده و داده‌های فعلی نمونه هستند.
